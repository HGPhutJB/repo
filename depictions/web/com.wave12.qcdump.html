Wave12 QuartzCore Dump

PucPucPuc · 1.0 · iOS 12 (arm64)

Temporary diagnostic tool for the 2712 project.

About 25 seconds after backboardd starts, it copies the QuartzCore code loaded in memory into a file in /var/mobile/Library/Accessibility/ so it can be analysed. It does not hook or change anything. Remove it once the files have been sent.
